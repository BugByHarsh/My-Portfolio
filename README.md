# Spatial UI Portfolio — React + Tailwind CSS

A React + Vite implementation of the Spatial UI portfolio experiment.

## Stack
- React 19
- Vite
- Tailwind CSS v4 via the official Vite plugin
- Lucide React icons

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The existing project preview images are imported from the repository's `images/` directory so Vite includes them in the production build. The contact form retains its existing Formspree endpoint.
